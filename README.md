# CircuitForge — Open-Source SPICE Circuit Workbench

I'm developing **CircuitForge**, an open-source SPICE-style circuit simulation workbench designed to make circuit design and analysis more accessible.

The interface is taking shape, with a schematic editor, component inspector, simulation controls, and dedicated panels for waveforms, operating points, netlists, and diagnostics.

This project is still under active development. Testing, optimization, and feature improvements are ongoing.

**Built with a 50/50 mix of AI-assisted coding and hands-on programming.**

Contributions, bug reports, and feature suggestions are welcome!
